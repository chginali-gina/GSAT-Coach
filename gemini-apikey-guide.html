Step by Step Guide

如何申請 Gemini API Key

3 分鐘搞定，讓學測陪跑系統和每日學習的 AI 功能動起來。

完全免費 · 免綁信用卡

什麼是 API Key？

API Key 就像一把「鑰匙」，讓我們的工具能去敲 Google Gemini AI 的門，請它幫你分析學習狀況。每個人要有自己的鑰匙，資料才不會混在一起。這把鑰匙只存在你自己的手機或電腦裡，不會被別人看到。

申請步驟

跟著做，每一步都有畫面說明

1

用 Google 帳號登入 AI Studio

打開瀏覽器，前往 Google AI Studio（學校 Google 帳號或私人 Gmail 都可以）：

aistudio.google.com
Get Started
第一次進入點這個按鈕，選擇你的 Google 帳號
提示：第一次使用會跳出「同意服務條款」，勾選同意後按 Continue 即可。系統問你所在國家時，選 Taiwan。
2

點選單裡的「Get API Key」

登入後，在選單找到有鑰匙圖示的選項：

Get API Key
通常在左側選單偏下方的位置

點下去就會進到「API Keys」管理頁面。

3

點「Create API Key」建立鑰匙

在 API Keys 頁面找到建立按鈕：

Create API Key
通常在頁面右上角

它會請你選一個「專案（Project）」。第一次用的話，直接選 Create API key in a new project（在新專案建立）最簡單。

如果出現 "Project creation is disabled"：這是 Google 偶爾的限制。先到 console.cloud.google.com 建一個新專案（取名如 my-gemini，不用綁信用卡），再回到這裡選那個專案即可。
4

複製你的鑰匙

建立成功後，畫面會出現一串以 AIza 開頭的長字串，這就是你的 API Key。點旁邊的複製圖示把它複製起來：

AIzaSyXXXXXXXX–你的專屬鑰匙–XXXXXXXX
長這樣，按右邊的複製鈕
重要：這把鑰匙等於你的帳號授權，不要截圖貼到網路上、不要傳給別人。貼到自己的備忘錄存好就行。
5

貼進工具，完成

回到「學測陪跑系統」，點下方的 AI 教練 分頁（每日學習則是 AI 覆盤 分頁），把鑰匙貼進「Gemini API Key」欄位，模型保持「自動」，按開始診斷，就能拿到你的專屬報告。

一次設定，長期使用：鑰匙會記在這台裝置的瀏覽器裡，之後同一台裝置、同一個瀏覽器打開就不用再貼。兩個工具共用同一把鑰匙。

常見問題

點問題展開答案

Q真的免費嗎？會不會被扣錢？
免費版不用綁信用卡，也不會扣錢。免費額度對每天做一次診斷或覆盤來說綽綽有餘，實際上限以 AI Studio 頁面顯示為準。除非你主動設定付款、綁卡升級，否則不會產生費用。
Q申請需要多久？要審核嗎？
不用審核，整個流程 3 分鐘內完成。鑰匙是即時產生的，複製貼上馬上就能用。
Q一個帳號可以申請幾把鑰匙？
同一個 Google 帳號可以建立多把。但對我們的工具來說，一把就夠了。
Q貼上鑰匙後出現錯誤怎麼辦？
先確認三件事：① 鑰匙完整複製（開頭是 AIza，前後沒有多的空格）② 網路正常 ③ 模型選「自動」，系統會自己找目前可用的最新模型。若還是不行，可能是當天免費額度用完，隔天會重置。
Q換手機或換電腦，鑰匙會不見嗎？
鑰匙存在你「當下使用的瀏覽器」裡，換裝置或清除瀏覽紀錄後需要重貼一次。建議把鑰匙存在自己的備忘錄裡備用。
